# 0.1.3

Updated some wording to make it clear what is happening in the 'new list' and 'rename list' dialogs.
After creating or importing a list, the list now opens.
Newly added list items are now added to the bottom instead of the top.

# 0.1.2

When adding an item, if the entered text contains newlines, each line becomes an item.
On each line, `- ` and `+ ` are stripped from the start of each.
This should make copying in 'lists' from other programs easier.
